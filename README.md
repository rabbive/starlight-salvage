Starlight Salvage is a top-down arcade game: pilot a salvage ship through an asteroid field, collect glowing crystals, dodge mines and asteroids, and deliver cargo to the mothership across five waves.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
